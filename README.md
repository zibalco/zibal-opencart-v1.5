# zibal gateway for opencart v1.5


لطفا محتویات را در فولدری که اپن کارت نصب شده کپی کنید.

سپس از قسمت افزونه ها - پرداخت ها درگاه پرداخت زیبال را فعال نمایید.

[https://zibal.ir]

## نکات

- پرداخت فقط برای سفارش‌هایی با واحد پول ریال (`IRR`، `RLS`) یا تومان (`TOM`، `IRT`، `TMN`) انجام می‌شود.
- تراکنش‌ها در جدول `zibal_transaction` نگهداری می‌شوند (جدول به صورت خودکار ساخته می‌شود).
- نتیجه هر تراکنش (موفق یا ناموفق) در تاریخچه سفارش ثبت می‌شود.
- زبان‌های فارسی (`persian`) و انگلیسی (`english`) پشتیبانی می‌شوند.
